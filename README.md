 基于加权集成学习的电商多仓商品需求预测与库存优化研究

 📖 项目简介
本项目基于“优购生活”电商平台的真实交易数据，系统分析了全国总仓及五大区域分仓的需求分布特征，构建了一种融合随机森林与梯度提升的加权集成预测模型，实现了对未来两周商品需求的准确预测。本项目已完成工程化重构，模块清晰，支持一键复现完整分析流程。

 📊 核心实验结果
   模型结构: 随机森林 (权重 0.369) + 梯度提升 (权重 0.631) 加权集成
   预测精度: 决定系数 (R²) 达到 0.877，平均绝对百分比误差 (MAPE) 为 10.16%
   应用价值: 预测未来两周全国总仓总需求 51,842 件，日均 3,703 件（相比历史日均下降14.2%），为分仓库存调配提供数据支持。
